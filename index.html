rclone OAuth client

Home page for a personal OAuth 2.0 client

This site hosts the home page and privacy policy for a private OAuth client used by rclone, an open-source command line tool for syncing files with cloud storage.

The client is not a public product or service. It exists so that its owner can run rclone against their own Google Drive account without relying on rclone's shared client ID.
